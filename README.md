# Лабораторные работы №1-3 и №5

**Выполнила:** Варвара Голубева, группа КИ25-20Б

## Описание проекта
Консольное приложение для работы с темами работ студентов. Поддерживает базовые темы, темы с группами и темы с оценками. Проект включает модульные тесты (xUnit), статический анализ (StyleCop) и сгенерированную документацию (Doxygen).

## Зависимости
- **.NET SDK 9.0**.
- Среда разработки: Visual Studio 2022 / VS Code.

## Как собрать проект из консоли
1. Клонируйте репозиторий и перейдите в папку с решением.
2. Выполните команды:
- Для запуска приложения:
   ```bash
   dotnet run --project lab1/lab1.csproj
- Для запуска тестов:
   ```bash
   dotnet test -c Release
- Сборка в Native AOT:
   ```bash
   dotnet publish -r win-x64 -c Release
